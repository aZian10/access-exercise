ANTES DE EMPEZAR

¿Qué vamos a aprender?

Una página web combina varias tecnologías. Cada una cumple una función y juntas permiten mostrar información y responder a las acciones del usuario.

01 / ESTRUCTURA

HTML: la estructura

HTML organiza el contenido de la página. Con sus etiquetas podemos crear títulos, párrafos, enlaces, listas e imágenes. Por ejemplo, el nombre del usuario y su estado de membresía se pueden mostrar con HTML.

<h1>Control de acceso</h1>
02 / PRESENTACIÓN

CSS: los estilos

CSS define cómo se ve la página: colores, tamaños, espacios y distribución de los elementos. Sirve para que la información sea clara y para que el sitio también se vea bien en celulares.

color: #22c55e;
03 / INTERACCIÓN

JavaScript: la lógica

JavaScript permite que la página reaccione a lo que hace el usuario. En este ejemplo, al escribir un documento se puede consultar el estado de la membresía y mostrar si el acceso está permitido o no.

button.addEventListener(...)
